# 財富階梯定位器

[《財富階梯》重點心得](../tutorials/wealth-ladder.md)裡連結的線上小工具，部署在 GitHub Pages：

<https://eddielincursor.github.io/research/wealth-ladder/>

只有一頁，沒有任何執行期套件，分成四段：

1. **盤點資產與負債**：現金、投資、退休帳戶、自住房、其他不動產、車子等資產，以及房貸、卡債信貸、車貸學貸等負債。工具會算出總淨值與流動淨值（現金＋投資 − 非房貸負債），可切換用哪一個定位，也可以調整美元匯率（預設 32）。
2. **你在哪一階**：顯示所在的 Level、對應的自由型態（超市、餐廳、旅行、房子、影響力自由）、在這一階的位置、距離下一階還差多少，以及六階的階梯圖與美國家戶約略分布。另附 0.01% 法則算出的「不必糾結的消費差額」。
3. **這一階該把力氣放在哪裡**：書中每一階的口訣、主要槓桿、該做的事、常見的坑和生活例子，再依你的數字給提醒，例如高利負債、緊急預備金月數、房產佔比過高、會產生收入的資產比例。
4. **往下一階還要多久**：依每月投入與假設年化報酬率，算出照目前速度到下一階的時間、想在 N 年內到達每月要投入多少，並畫出對數刻度的淨值預估圖與各階里程碑表。

網址 `#` 後面會記住目前的設定，可以存成書籤每季回來更新。數字不會上傳到任何地方。

計算方式：年化報酬率視為有效年利率，月利率為 `(1 + r)^(1/12) − 1`，每月月底投入，未計稅費與通膨。Level 1 的進度線性計算，Level 2 以上用對數刻度（每 10 倍走完一階）。

## 本機執行

```bash
cd wealth-ladder
pnpm install
pnpm dev      # http://127.0.0.1:47324
pnpm test     # 計算函式的單元測試
pnpm build    # 型別檢查並輸出到 dist/
```

推到 `main` 後，`.github/workflows/pages.yml` 會把這個工具和 `budget-lite/` 一起建置，分別部署到 `/wealth-ladder/` 與 `/budget/`，根目錄是 `site-home/index.html` 的工具列表。
