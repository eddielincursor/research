# 薪水分配與投資試算

這是[理財篇教學](../tutorials/budgeting-ratios.md)的配套網頁工具，分成兩個步驟：

1. **財務規劃表**：填入稅後月收入和每月必要支出，選一種分法（631、333、5311、50/30/20、六罐子或自訂比例），工具會算出每一格每月和每年要放多少錢。
   - 依必要支出佔收入的比例建議適合的分法。必要支出超過收入 70% 時，會提醒先處理現金流。
   - 用一條分配長條顯示比例，並標出必要支出的位置，一眼看出生活費夠不夠用。
   - 估算緊急預備金：可選 3 或 6 個月，扣掉已存的金額後，算出還要幾個月才存得到。
   - 用同一份收入比較五種分法，看每種分法的生活費和投資金額。
   - 按「帶入並開始試算」，把投資那一格的金額帶進投資計算機。
2. **投資計算機**：輸入單筆投入、每月投入、年化報酬率和投資年數，看最後會累積多少。
   - 可切換月初或月底投入，也可設定每年投入金額成長率和通膨率，並切換成以今日購買力顯示。
   - 本金與報酬的堆疊面積圖，標出「報酬超過投入」的那一年。
   - 情境比較：同時畫出報酬率 ±2% 和 0%（只存不投資）的曲線。
   - 逐年明細表，可下載 CSV，Excel 開啟時中文不會亂碼。
   - 目標金額：算出照目前設定多久會達標，以及要在指定年數內達標，每月需要投入多少。
   - 重點整理：報酬超過本金的年份、72 法則和實際翻倍年數，以及通膨換算後的實際價值。

## 計算方式

- 年化報酬率視為有效年利率，換算成月利率的公式為 `(1 + r)^(1/12) − 1`。所以單筆投入 100,000、年化 6%，一年後正好是 106,000。部分網站直接用 `r / 12`，數字會略高一點。
- 分配金額取到整數元，並用最大餘數法處理尾數，各格加總一定等於收入。例如 50,000 用 333 分配，結果是 16,667 / 16,667 / 16,666。
- 所有結果只用於試算，不代表投資建議，實際報酬會有波動。

## 本機執行

需要 Node.js 20 以上和 pnpm。

```bash
cd finance-tools
pnpm install
pnpm dev --port 47321
```

打開 <http://127.0.0.1:47321>。

其他指令：

```bash
pnpm test   # 分配與投資計算的單元測試
pnpm lint
pnpm build
```

## 技術

Next.js 16、React 19、TypeScript、Tailwind CSS v4、shadcn/ui、Recharts，以及 Vitest 單元測試。計算邏輯放在 `src/lib/budget.ts` 和 `src/lib/invest.ts`，畫面元件放在 `src/components/`。
