# 你的月薪在同齡的哪裡

[平均薪資和中位數](../tutorials/salary-median.md)這篇文章搭配的網頁，部署在 GitHub Pages：

<https://eddielincursor.github.io/research/salary/>

用行政院主計總處 114 年（2025）工業及服務業受僱員工的每月經常性薪資，做三件事：

1. 說明平均 47,884 元和中位數 38,406 元為什麼差這麼多，以及為什麼 69.74% 的人低於平均。
2. 列出六個年齡階段的中位數（當作及格線）和平均數（當作前段線）。
3. 輸入年紀和月薪，看落在哪個階段、和同齡中位數差多少，以及大約贏過同齡多少人。

全體的位置用表 9 的十等分位，是官方分組。同齡百分比是粗估：官方沒有公布各年齡的月薪百分位，這裡用全體分布的形狀，再用 113 年各年齡全年總薪資的四分位去調整寬窄。

請填本薪加每月固定津貼。加班費和年終不要算進去。數字只留在瀏覽器，網址 `#a=32&s=42000` 這種形式可以存成書籤。

## 本機執行

```bash
cd salary-check

pnpm test
pnpm build
```
